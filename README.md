# java-lotto-precourse

### 📌 요구사항 요약
구매 매수만큼 로또를 발행하고, 당첨 내역과 수익률을 출력한다.
<br/>

### 📝 구현할 기능 목록
#### 1. 구매 비용 입력
- 조건
- [x] `Console`의 `readLine()`을 활용
- 예외
- [x] 100,000원 초과 시 예외 처리
- [x] 입력 제한이 없으므로, 정수 변환 전 길이 검사
- [x] 1,000의 배수가 아니거나 음수일 경우 예외 처리
- [x] 숫자 외 문자 입력 시 예외 처리
#### 2. 로또 발행
- 조건
- [x] 구매 금액을 1,000으로 나눈 수만큼 로또 발행
- [x] `Randoms`의 `pickUniqueNumbersInRange()`를 활용
- [x] 1-45 범위에서 중복없이 6개 랜덤 숫자 추출
#### 3. 구매 내역 출력
- 조건
- [ ] 발행한 로또 번호 오름차순으로 정렬하여 출력
#### 4. 당첨 번호 · 보너스 번호 입력
- 조건
- [ ] `Console`의 `readLine()`을 활용
- 예외
- [ ] `,` 쉼표로 구분하고, 다른 문자나 공백이 있는 경우 예외 처리 
- [ ] 1-45 범위를 벗어나면 예외 처리
- [ ] 중복이 있을 경우 예외 처리
- [ ] 당첨 번호가 6개가 아니라면 예외 처리
- [ ] 보너스 번호가 1-45 범위의 정수가 아니라면 예외 처리
- [ ] 보너스 번호가 당첨 번호에 포함된다면 예외 처리
#### 5. 당첨 내역 및 수익률 출력
- 조건
- [ ] 당첨은 1등부터 5등까지 있고, 기준과 금액은 아래와 같다
```
1등: 6개 번호 일치 / 2,000,000,000원
2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
3등: 5개 번호 일치 / 1,500,000원
4등: 4개 번호 일치 / 50,000원
5등: 3개 번호 일치 / 5,000원
```
- [ ] 입력 받은 당첨 번호와 발행한 로또들을 비교해 당첨 판별
- [ ] 당첨 내역 종합 출력
- [ ] 수익률은 소수점 둘째 자리에서 반올림
<br/>

### 💡 스스로 판단한 규칙
- 구매 금액 제한이 따로 없는데, `복권및복권기금법시행령 제3조`에 따라 1회 최대 10만원까지만 허용.
